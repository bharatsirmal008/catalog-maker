# Demo Script

## Demo 1: Customer Experience
1. Open public catalog on Template A.
2. Browse categories and perform a search.
3. Open a product, select a variant, and add to wishlist.
4. Show WhatsApp enquiry functionality.

## Demo 2: Admin & Sync
1. Login to admin dashboard.
2. View product management.
3. Show Shopify & WooCommerce connection configurations.
4. Trigger manual synchronization and show sync history.
5. Switch catalog template to Template B and view changes on customer frontend.
